# 顶功编码

本文中的 `+` 表示一组同时按下并全部松开的键，空格只有写在组合中时才与其他键并击；“单独空格”表示不带其他键单独按下并松开。

## 单音节词

左手声介的固定简码打完后自动上屏。例如单独按下并松开 `f`，输入“的”。

左手声介加右手韵调，得到完整的带调音节。此时先看首选：若首选就是所需单字，继续打下一个词的不带空格音节即可顶屏；若不是，追加辅助码或选重。例如并击 `s+g+i` 输入 `bing1`：

<Window :input="输入单字" />

在使用横排候选的前端中，左手声介同时带右手单引号 `'`，可直接输入该声介的一简词，也就是固定表中的第二项。固定简码来自 `snow_yipin.fixed.txt`；普通完整音节的候选会随使用调频。

## 多音节词

第一个音节双手并击，不带空格；后续音节双手带空格并击，表示继续当前词。例如“冰雪”为 `s+g+i`，再打 `d+r+m+空格`：

<Window :input="输入二字词" />

最多只需输入前四个音节，后续内容可以联想，因此五字及以上词也按前四个音节检索。当前词出现在首选后，可用下一个词不带空格的音节顶屏，或单独空格确认。

多音节词与单字使用同一份带调拼音词库，支持动态调频。若候选里没有所需词，可以使用[缓冲造词](#缓冲造词)。

## 形旁辅助码

完整单音节后，可以用单手带空格并击，追加该字形旁的辅助码。每个字使用 `snow_xingpang.dict.yaml` 指定的形旁；大多数形旁按读音的声介编码，再用左手对应的声介键位带空格并击。它不是输入这个部件的完整音节，也不是按笔顺逐笔输入。

例如“奕”的形旁为“大”，其声介为 `d`，对应左手 `f`。先并击 `d+j` 输入 `yi4`，再并击 `f+空格`，筛出“奕”：

<Window :input="输入左手辅助码" />

十一个常用形旁可以改用右手单键带空格，减少跨手移动：

| 形旁 | 右手键 | 形旁 | 右手键 |
| --- | --- | --- | --- |
| 石 | `y` | 月 | `u` |
| 钅 | `i` | 纟 | `o` |
| 讠 | `p` | 氵 | `h` |
| 亻 | `j` | 扌 | `k` |
| 木 | `l` | 忄 | `n` |
| 山 | `m` | | |

例如同样先输入 `yi4`，再并击 `k+空格`，用“扌”筛出“抑”：

<Window :input="输入右手辅助码" />

候选注释会提示形旁及其辅助编码。其余形旁的声介键位参见[拼写规则](./spelling)；“儿、而、耳、二、邑”等使用零声母声介，对应左手 `z+v` 带空格。追加辅助码后仍可用下一词的编码顶屏。

## 选词和编辑

| 操作 | 并击或按键 |
| --- | --- |
| 确认当前候选 | 单独空格 |
| 直接选第 2～6 个候选 | `2`～`6` |
| 选择当前项之后的第 1～4 项并确认 | 并击 `jk`、`kl`、`jl`、`j;`（横排候选） |
| 上一页、下一页 | 并击 `hk`、`hl`，或 `[`、`]` |
| 删除上一个音节 | `BackSpace` |
| 取消当前输入 | `Escape` |

选重并击借用右方向键，依赖前端的横排候选设置；竖排候选时请直接用数字键选重。选重并击已包含确认动作，不需要再按空格。

右手单独输入标点的组合见[高级功能](./advanced#标点与符号)。

## 缓冲造词

在没有编码时，并击 `j+i+o` 开启缓冲，也可按 `Control+j`。随后按平时的方法拆分输入目标词，顶功和左手简码仍有效，但已确认的文字会留在缓冲区中。

例如把“冰雪”作为一个整体输入：开启缓冲后分别打 `s+g+i`、`d+r+m`，此时“冰”已确认、“雪”仍为当前候选；单独空格确认“雪”，再单独空格将“冰雪”整段上屏。下一次可按二字词的方法输入“冰雪”。

整段上屏后自动退出缓冲。重复并击 `jio` 或按 `Control+j` 只会保持开启，不会关闭；需要放弃这次输入时用 `Escape` 清空内容；清空内容不会关闭缓冲，下一次整段上屏后才恢复正常顶屏。

## 整句模式

在 Rime 方案选单中把“顶功”切换为“整句”，可以练习每个音节的声介和韵调。完整音节可以连续输入，不需要给后续音节带空格；左手声介简码仍会确认片段。切回“顶功”后恢复本页的分词输入规则。

也可以在 `snow_yipin.custom.yaml` 中设置启动时的模式，重新部署后生效：

```yaml
patch:
  switches/@4/reset: 0 # 0 为整句，1 为顶功
```

共用词库的配置见下文的[词库设置](#词库设置)，补丁文件和数据备份见[个性化与数据管理](/#个性化与数据管理)。冰雪一拼不提供其他方案的固定候选操作快捷键，也不提供以词定字和 Unicode 码点输入。
