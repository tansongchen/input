# 高级功能

## 标点与符号

右手单独按下并松开下表的组合，可以输入标点。无需带空格，不要与左手声介组合；需要在音节后筛选形旁时，使用[单手带空格](./basic#形旁辅助码)。

| 并击 | 标点 | 并击 | 标点 |
| --- | --- | --- | --- |
| `h` | 、 | `j` | ， |
| `k` | 。 | `l` | ？ |
| `y` | —— | `u` | “ |
| `i` | ” | `o` | ： |
| `p` | ； | `n` | …… |
| `m` | ！ | `ui` | （ |
| `io` | ） | `uo` | 《 |
| `up` | 》 | `m,` | · |
| `,.` | ～ | `m.` | ‘ |
| `m/` | ’ | | |

普通数字和不在并击字母表中的符号可以直接输入；字母表内的按键优先作为并击解释。需要连续英文时，切换至西文模式后输入。

## 功能并击

| 并击 | 功能 |
| --- | --- |
| `jk`、`kl`、`jl`、`j;` | 选择当前项之后的第 1～4 项并确认（横排候选） |
| `hk`、`hl` | 上一页、下一页 |
| `jio` | 开启缓冲，重复操作保持开启 |
| `jkl` | 统计说明与本机各时段统计，命令为 `itj` |
| `uio` | 各设备分列统计，命令为 `itjf` |
| `m,.` | 所有设备合并统计，命令为 `itjh` |

这些组合都在全部松开后执行。缓冲输入的确认和退出方法见[缓冲造词](./basic#缓冲造词)。

## 输入统计

并击 `jkl` 后选择“📖 统计功能说明”或需要的报告；并击 `uio`、`m,.` 分别查看各设备和所有设备合计。冰雪一拼的统计前缀为 `i`，这三组并击会直接生成完整命令。

## 个人设置与同步

冰雪一拼与其他方案共用音节码用户词典，可以同步已有词频；固定简码由本方案的固定词表提供。个人词库和调频设置见[词库设置](./basic#词库设置)，补丁文件和备份见[个性化与数据管理](/#个性化与数据管理)，常见操作见本页的[编辑与切换](#编辑与切换)。

## 编辑与切换

`Control` 在键盘上通常标为 `Ctrl` 或 `⌃`。有编码时，可用 `Control+p/n/b/f` 代替上、下、左、右，`Control+a/e` 移到开头或末尾，`Control+h` 退格，`Control+d` 删除，`Control+g` 取消当前输入。本方案的退格按音节删除；选词和翻页的功能并击见上文，`[`、`]` 只用于翻页。

| 操作 | 按键 |
| --- | --- |
| 切换下一个方案 | `Control+Shift+1` |
| 切换中西文 | `Control+Shift+2` |
| 切换全半角 | `Control+Shift+3` |
| 切换简繁 | `Control+Shift+4` |
| 切换中西文标点 | `Control+Shift+5` |

在 Rime 方案选单中切换“整句／顶功”模式。`Control+j` 或并击 `jio` 开启缓冲，重复操作保持开启；完整操作见[缓冲造词](./basic#缓冲造词)。前端或系统占用组合键时，可通过前端菜单或 Rime 方案选单操作。
