# 顶功编码

冰雪飞花具有三个顶功模式：

1. 冰雪飞花・二码顶：又称冰雪飞单，是单字输入方式；
2. 冰雪飞花・四码顶：又称冰雪飞码，是主词辅单的输入方式；
3. 冰雪飞花・五二顶：又称冰雪飞延，是主单辅词的输入方式。

基于上一节关于部件字和复合体字规则的介绍，容易得出以下规律：

- 部件字的全码的格式为：`AB`、`ABB` 或 `ABBB`
- 复合体字的全码的格式为：`AUB` 或 `AUBB`

全码码长为二的字没有简码；部分全码码长大于等于三的字存在一级简码（即只打全码的第一码）或二级简码（即只打全码的前两码）；部分全码码长为四的字存在三级简码（即只打全码的前三码）。对于各种全码和简码，其能否顶功上屏取决于所处的顶功模式，介绍如下：

## 二码顶

单字编码可以为 `A_`, `AU`, `AUB`, `AUBB`。即除了一级简码，其他都可以顶功上屏。

## 四码顶

单字编码可以为 `A_`, `AU_`, `AUB`, `AUBB`。即除了一级、二级简码，其他都可以顶功上屏。

下面我们来介绍词语的编码。首先我们定义每个字的构词码：若一个部件字的全码是 `AB`，则重复末码变成 `ABB`；其余情况，构词码是全码的前三码。由于 `B` 是 `U` 的子集，不失一般地下面假定每个字的构词码都具有 `AUB` 的格式。

词语编码为：

- 二音节词：格式为 `A₁U₁A₂U₂`, `A₁U₁A₂U₂B₂`, `A₁U₁A₂U₂B₂B₁`。
- 三音节词：格式为 `A₁A₂A₃U₃`, `A₁A₂A₃U₃B₁`, `A₁A₂A₃U₃B₁B₂`。
- 四音节词：格式为 `A₁A₂A₃A₄`, `A₁A₂A₃A₄B₁`, `A₁A₂A₃A₄B₁B₂`。
- 多音节词：格式为 `A₁A₂A₃A₄A₅..Aₙ`, `A₁A₂A₃A₄A₅..AₙB₁`, `A₁A₂A₃A₄A₅..AₙB₁B₂`，其中第五个及之后的 `A` 集合编码大写。

## 五二顶

单字编码与二码顶相同。词语编码为 `AUAU_`, `AUAUB_`, `AUAUBB_`。相比于四码顶，这相当于把二码字后的空格挪到了所有词语的后面。

## 大字集的单字输入

### 扩展编码

由于本方案常规编码只有 43800 个编码空间，难以在大字集中保持低重。因此，本方案又额外规定一种不限最大码长的编码方式：

- 部件字：声母 + 该部件的基本拆分中的全部字根
- 复合体字，余部是部件：声母 + 正根 + 余部部件的基本拆分中的全部字根 + 正部除了正根之外的全部字根
- 复合体字，余部是复合体：声母 + 正根 + 余部第一部分的首根 + 余部第二部分以及之后的全部字根 + 余部第一部分的第二个及之后的全部字根 + 正部除了正根之外的全部字根

容易看出，常规编码是此扩展编码的前缀。因此如果按照常规编码打出之后觉得重码多，只需要按照此规则继续打几码即可。此外，扩展编码是一种「全息编码」，即汉字中的每一个笔画所在的字根都出现在编码中。

### 纯形输入

如果不知道一个字的读音，可以使用 `u` 来代替其打法中的声母，其余按照常规编码或扩展编码正常取码。
