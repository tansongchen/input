## 以词定字

<!-- #region word-to-char -->

在本方案中，输入不常用的单个汉字的推荐方法是以词定字，也即先想出一个包含该字的词，打出该词后从词里截取相应的单字。以词定字的快捷键为 `[` 和 `]`，按 `[` 上屏词的首字，按 `]` 上屏词的末字。

例如，想打「熙」这个单字时，想到它出现在四字词「熙熙攘攘」中，因此先打「熙熙攘攘」使其出现在首选：

<Window :input="输入定字一" />

然后按 `[` 即可上屏「熙」。

使用以词定字要求用于定字的词必须处于选中状态。一般来说，可以通过追加编码的方式把词提升到首选来选中该词，但如果打完全部编码后词仍然不在首选，就需要先用光标键选中该词再定字。例如，想用「采薇」一词来输入「薇」，但打完词的全部编码之后词仍然不在第一位，此时就需要先用右箭头（或下箭头）选中该词，再按 `]` 完成定字。

## 略码

<!-- #region abbreviation -->

略码是输入特定结构的词的办法，能够避免一些词带来的不确定性，同时明显减少输入单字的机会。以下我们用全角字母「ＡＢＣ……」来表示词中的待定成分。

由于本方案中「的」和「了」是一键字，且可以标点顶屏，所以「Ａ的」「Ａ了」「ＡＢ的」「ＡＢ了」这样的词就不必按词打，打完前面的部分之后打相应的标点键就可以了，这也是一种特殊的略码。下面是更一般的略码形式：

### 完整重复

完整重复整个词的「ＡＡ」、「ＡＢＡＢ」、「ＡＢＣＡＢＣ」……型：略码为 `[`，如「吃吃」是 `yi[`；双音节及以上的词，因为 `[` 已经被占用，所以略码为 `A`，如「尝试尝试」是 `yviA`。

对二字词来说，还有一种特殊的「ＡＡＢＢ」型，略码为 `O`，如「可可爱爱」是 `krO`。

### 部分重复

重复词的首字或末字的「ＡＡＢ」、「ＡＢＢ」、「ＡＡＢＣ」……型，略码为 `E`（重复首字）和 `I`（重复末字）：如「打打牌」是 `dpaiE`，「打打篮球」是 `dlqouE`，「睡觉觉」是 `vjuI`。

### 插入重复

「Ａ不Ａ」「Ａ一Ａ」「Ａ的Ａ」「Ａ了Ａ」「Ａ了一Ａ」「Ａ啊Ａ」「Ａ呀Ａ」型：略码分别为 `B`, `F`, `D`, `L`, `K`, `R`, `U`，如「好不好」是 `haB`；「ＡＢ不ＡＢ」以及更长的词也一样，比如「可爱不可爱」 `krB` 打出来。这里 `B, F, D, L, R` 表示的是相应插入成分的声码，便于记忆。

「Ａ着Ａ着」：略码为 `W`，表示「着」的声码

「Ａ来Ａ去」：略码为 `Q`，表示「去」的声码

### 其余略码形式

还有一些常见的略码形式没有安排，可以根据自己的需要来设计：

「Ａ个Ｂ」：只插入不重复，如「吃个饭」

「Ａ了ＡＢ」「Ａ不ＡＢ」「Ａ里ＡＢ」：既重复又省略了一个字，如「开不开心」
<!-- #endregion abbreviation -->

### 笔画辅助码

## 输入统计

<!-- #region statistics -->

输入本页所列的统计命令后，首选是“📖 统计功能说明”，后面依次为本机当前方案的今日、本周、本月、本年和全部统计。选择说明或某一项报告，即可把全文输入到当前应用，便于阅读和保存。

### 选择时段和设备

在统计命令末尾追加下列后缀，可以只查看一个时段；不追加则显示各个当前时段。本周从周一开始，日期按本地时间计算。

| 命令后缀 | 范围 |
| --- | --- |
| `r`、`z`、`y`、`n`、`q` | 今日、本周、本月、本年、全部 |
| `r-1`、`z-1`、`y-1`、`n-1` | 昨天、上周、上个月、去年；数字可换为更早的偏移 |
| `20261026` | 2026 年 10 月 26 日 |
| `202610`、`2026` | 指定月份、年份 |
| `2026w44` | 指定 ISO 周，周一开始 |

默认仅看本机。在时段后缀之前加 `f`，可分列所有有数据的设备；加 `h`，可合并所有设备。例如在统计命令后追加 `fr-1`，表示各设备昨天的统计；追加 `h2026`，表示所有设备 2026 年的合计。方案之间始终分开统计，其他设备的数据需先通过 Rime 同步合并到本机。

### 如何理解指标

| 指标 | 含义 |
| --- | --- |
| 词数、字数 | 上屏次数、上屏文字的 Unicode 字符数；标点和数字也计入字数 |
| 按键、有效按键 | 实际击键数，以及扣除退格和被退格删掉的输入后的击键数 |
| 用时 | 相邻击键间隔之和，达到 5 秒的间隔视为停顿，不计入 |
| 均速、极速 | 每分钟字数；极速来自累计至少一分钟的输入窗口，显示值不低于均速，不满一分钟时不显示 |
| 击键 | 每秒按键数 |
| 码长、理论码长 | 实际按键数、有效按键数分别除以上屏字数 |
| 键准 | 有效按键数占实际按键数的比例 |
| 平均词长、多字词占比 | 每次上屏的平均字数，以及多字上屏贡献的字数占比 |
| 词长分布、码长分布 | 每次上屏的字数分布和有效按键数分布，十及以上合为一档 |

组合键整组算一次击键，冰雪一拼的一组并击也算一次，松开不另外计数。全局英文和临时西文输入不计；没有编码时单独输入的空格、回车等排版空白不计。取消整段编码时，这段尚未上屏的击键丢弃。统计命令本身也不计。

顶功触发键属于下一个词，计入下一个词的码长；因此统计反映的是每次上屏实际分到的按键。这里的“词”指一次上屏，可能是单字、词组或整句。

### 保存与同步

数据保存在 `snow_statistics.userdb`，同步快照为 `snow_statistics.userdb.txt`，与 Rime 用户词典一起同步。各设备用 `installation.yaml` 中的 `installation_id` 区分；缺少该标识时只有功能说明，不记录或显示统计数据。修改设备标识后旧数据仍在原标识下，详见[数据管理](/#同步、备份与恢复)。

若希望排除某类功能输入，可在所用方案的补丁中设置 `statistics/exclude`。例如在冰雪四拼、冰雪三拼或冰雪键道中排除所有 `o` 引导的输入：

```yaml
patch:
  statistics/exclude: ["o.*"]
```

正则与上屏前的完整编码匹配；它不屏蔽没有编码时直接放行的字符。修改配置后重新部署。

## Unicode 码点输入

<!-- #region unicode-input -->

在本页所列的 Lua 引导前缀后输入十六进制 Unicode 码点，即可直接输入对应字符。例如码点 `4e00` 对应“一”，`20000` 对应扩展 B 区的“𠀀”。大小写均可，最多六位，候选注释显示 `U+` 编码和所属区块；不需要输入 `U+` 本身。

码点输入用来直接得到字符；Unicode 注解用于辨认已有候选。冰雪一拼不提供码点输入。

<!-- #endregion unicode-input -->

## 笔画的地区字形

<!-- #region shape-sources -->

笔画反查可以使用不同来源记录的笔顺。默认使用 `G`，需要兼容其他地区字形时，在所用方案的补丁文件中设置：

```yaml
patch:
  translator/shape_sources: [G, T]
```

多个来源取并集，标签区分大小写。可用标签为 `G`、`H`、`T`、`J`、`K`、`N`、`V`、`M`、`S`、`B`、`U`。标签沿用原始笔画表，表示可使用的笔顺来源，不会改变字体的显示字形。

省略此设置或设为 `null` 时默认 `[G]`；设为 `[]` 时只保留无来源标签的记录；无标签记录始终可用。修改后重新部署即可，不需要重新生成词典。

此设置只影响笔画反查和相关笔画辅助码的筛选、提示，不会隐藏普通拼音候选。笔画表未收录的字不会被辅助码排除；已收录的字则只匹配所选来源允许的笔顺。独立的冰雪笔画方案也支持它。
